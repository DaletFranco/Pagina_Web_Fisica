Problema 1: Integración Numérica de Flujos Adimensionales

Estudio de trayectorias, líneas de corriente y campos de velocidad instantáneos con fuente lineal 2D.

Ecuación del Flujo Adimensional:

$$\frac{\mathrm{d}\mathbf{X}'}{\mathrm{d}t'} = \frac{1}{r'}\hat{\mathbf{r}} + t'\,\hat{\mathbf{x}}$$

Para $t' \ll 1$ domina la fuente radial. Para $t' \gg 1$ domina la advección uniforme hacia $+\hat{x}$.

Ecuación del Flujo con Torbellino Decayente:

$$\frac{\mathrm{d}\mathbf{X}'}{\mathrm{d}t'} = \frac{1}{r'}\hat{\mathbf{r}} + \beta\, e^{-t'}\,\frac{1}{r'}\hat{\boldsymbol\theta}, \qquad \beta \equiv \frac{\Gamma_0}{Q}$$

El parámetro $\beta$ mide la intensidad inicial del vórtice. Al decaer exponencialmente la circulación, el flujo se relaja a una fuente pura.

Para $\beta=0$ las trayectorias son radiales. A mayor $\beta$, se observa una marcada rotación inicial que se relaja a medida que $t \to \infty$.

Ecuación del Flujo con Corriente Oscilante:

$$\frac{\mathrm{d}\mathbf{X}'}{\mathrm{d}t'} = \frac{1}{r'}\hat{\mathbf{r}} + \cos(\Omega t')\,\hat{\mathbf{x}}, \qquad \Omega \equiv \frac{\omega Q}{2\pi U_0^2}$$

$\Omega$ representa la frecuencia reducida. $\Omega \ll 1$ causa oscilación lenta, mientras que $\Omega \gg 1$ promedia advección nula.

Problema 3: Estimación de Parámetros — Vórtice de Burgers

Ajuste simultáneo de pesos neuronales y parámetros físicos $(\alpha, \Gamma, r_0^2)$ sobre datos PIV experimentales.

Campo de Velocidad del Vórtice de Burgers:

$$u_x = -\alpha x - \frac{\Gamma\,y}{2\pi r^2}\Big[1-e^{-r^2/r_0^2}\Big], \qquad u_y = -\alpha y + \frac{\Gamma\,x}{2\pi r^2}\Big[1-e^{-r^2/r_0^2}\Big]$$

Los parámetros de contracción radial ($\alpha$), circulación far-field ($\Gamma$) y radio del núcleo ($r_0$) se infieren durante la retropropagación en PyTorch.

Reporte de Correcciones y Optimización de Memoria

Detalle de las mejoras aplicadas al código Python y a la infraestructura de renderizado web.

1. Corrección de Cadenas de Escape en Comentarios

Se convirtieron todas las cadenas multilínea y docstrings con expresiones en LaTeX a notación raw (r"""..."""). Esto corrigió fallos donde Python interpretaba:

  • \beta $\to$ caracter de retroceso (ASCII Backspace \x08).
  • \tau y \theta $\to$ caracter Tabulación (\t).
  • \frac $\to$ caracter Form Feed (\x0c).
  • \alpha $\to$ caracter Campana (ASCII Bell \x07).

2. Reparación de Formato Markdown y Ortografía

Se corrigieron artefactos de sustitución textual corruptos y errores dactilográficos:

  • 1/r*2* $\to$ $1/r^2$
  • r*2*-->max(r*2,ϵ) $\to$ $r^2 \to \max(r^2, \epsilon)$
  • ϵ = 10*−8* $\to$ $\epsilon = 10^{-8}$
  • Corrección de acentuación: ecuación, computacional, código, órdenes, precisión.
  • Eliminación del bloque duplicado de conclusiones en el Problema 3.

3. Optimización Radical de Memoria (RAM)

Para solucionar el problema de congelamiento del navegador y consumo excesivo de memoria:

  • Matplotlib Backend Backend 'Agg': Generación de gráficos sin levantar ventanas interactivas pesadas GUI.
  • Liberación Explícita: Invocación de plt.close(fig) inmediatamente después de renderizar cada gráfico.
  • Generación de Activos Livianos: Exportación a SVG/PNG optimizados y animaciones GIF comprimidas.
  • Carga perezosa (Lazy Loading): La interfaz web carga gráficos y animaciones solo cuando la pestaña correspondiente entra en pantalla.
